# Serwis Maszyn 🔧

Książka serwisowa maszyn na Androida: oleje (rodzaj, litry), filtry z zamiennikami,
licznik motogodzin, wyliczanie terminów wymian i codzienne powiadomienia o 8:00.

**Pobierz aplikację:** zakładka *Releases* → najnowszy `SerwisMaszyn.apk`.

Dane są zapisane w telefonie. Kopię zapasową wyślesz z ekranu głównego → „Kopia zapasowa”.

Zmiana `index.html` lub plików w `android/` automatycznie buduje nową wersję APK.
